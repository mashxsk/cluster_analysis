# cluster_analysis
A desktop application built with Python and PyQt for cluster analysis of world countries based on macroeconomic indicators. Features an interactive GUI.

# Features
* Interactive Graphical User Interface (GUI) built with PyQt.
* Data loading, cleaning, and processing capabilities.
* Implementation of clustering algorithms to group countries with similar economic profiles.
* Visual representation of the analysis results.

# Technologies
* **Language:** Python
* **GUI Framework:** PyQt
* **Data Processing & ML:** *Pandas, NumPy, scikit-learn, matplotlib*
